数据流（recognize）：
  source → loadImage → OcrImageData → ImageProcessor.preprocess → Float32
       → Backend.load (model cached) → tf.predict / ort.run
       → postprocess → TextBox[] / TextLine[] → OcrResult → cache.set
                                                              ↑ dispose

依赖方向：Layer N 只能调用 Layer N+1；Recognizer 之间通过 DI 而非 import。
